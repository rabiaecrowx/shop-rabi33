# rabi3.

A black-and-orange shopping experience built with React and Vite. rabi3 is a fictional independent store for sneakers, tech, apparel and after-hours essentials.

## Run it locally

```bash
npm install
npm run dev
```

Open the local URL Vite prints (usually `http://localhost:5173`).

## Production build

```bash
npm run build
npm run preview
```

## What's included

- Responsive landing page with a bold hero, category edits, product grid, promo panel, reviews and newsletter
- Product filtering and sorting
- Quick-view product modal with size, quantity and add-to-bag controls
- Slide-out cart and wishlist panels with quantity controls and localStorage persistence
- Search panel with live results
- Mobile navigation and responsive layouts for phone, tablet and desktop
- Local fonts and product imagery (no external image dependencies)

## Stack

- React 19
- Vite 8
- Lucide React icons
- Plain CSS with custom properties
